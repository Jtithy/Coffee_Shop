# ☕ CoffeeHub – Coffee Shop Website

A modern and visually appealing coffee shop landing page designed to showcase premium coffee, popular menu items, special offers, and coffee shop information.

CoffeeHub provides a clean and elegant web interface with a warm coffee-inspired color palette, attractive sections, and interactive-looking UI elements.

## ✨ Features

- **Navigation Bar** – Easy navigation between different website sections.
- **Hero Section** – Attractive introduction with a coffee-themed design and call-to-action buttons.
- **Services Section** – Highlights premium quality, fast delivery, secure payment, and customer support.
- **Popular Coffee Menu** – Showcases different coffee varieties with descriptions, prices, and Add to Cart buttons.
- **About Us** – Introduces CoffeeHub's mission and commitment to quality.
- **Special Offers** – Displays promotional discounts on selected coffee products.
- **Newsletter Subscription** – Provides an email subscription interface.
- **Footer Section** – Includes quick links, social media links, and contact information.
- **Hover Effects** – Smooth CSS hover effects for buttons and navigation links.

## 🛠️ Technologies Used

## 🚀 Getting Started

Follow these steps to run the project locally.

**1. Clone the repository**

```bash
git clone https://github.com/Jtithy/Coffee_Shop.git
```

**2. Navigate to the project directory**

```bash
cd Coffee_Shop
```

**3. Run the project**

Open `index.html` in your preferred web browser.

You can also use the Live Server extension in Visual Studio Code for a better development experience.
